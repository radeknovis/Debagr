# Debagr imagery

Generated on 14 November 2026 with the built-in imagegen tool.

## Primary direction: the iPhone travels

Your paired Mac stays at home. Your iPhone is with you at a café or airport,
on a different Wi-Fi network. A private VPN connects the phone directly to
the paired Builder. No cable host needs to travel with the phone.

[Roaming prompts and provenance](roaming-manifest-v1.json) records the exact
prompts, checksums and image metadata. The phone is shown without a cable or
nearby computer. These are conceptual campaign images, not hardware evidence.
Wi-Fi and a private VPN are required; cellular-only operation is unsupported.

## Secondary direction: optional cable sharing

The earlier set focuses on the USB via Mac feature. It should be used only in
that feature's material, rather than as the lead product story.

| Asset | Dimensions | Intended use |

| [Cable social](cable-social-v1.png) | 1254 × 1254 | Square social graphic with Debagr / USB via Mac text |

These are AI-generated conceptual product illustrations. The physical cable
connects the phone to the nearby laptop; the blue dotted path represents the
private network between that laptop and the paired Builder. Screens are blank.
The images are separate from native UI screenshots and hardware test evidence.

[Manifest and full prompts](manifest.json) records the tool, dimensions, file
sizes, checksums and exact prompt used for each image. Original generation
outputs were copied without resizing or retouching. Existing website assets
have not been replaced by this set.
