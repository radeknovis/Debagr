Debagr

Install to first deployment

  1. On your Apple-silicon build Mac, install current Xcode and Debagr: brew install --cask radeknovis/debagr/debagr.
  2. Pair your iPhone or iPad over USB, grant trust, enable Developer Mode, and test a local signed build.
  3. Connect the Mac and device to your private VPN. With the device nearby, open Debagr and choose Set Up Remote Device. Select the paired device, its nearby service and its VPN address. Confirm the selections refer to the same physical device, then choose Connect device.
  4. Leave Debagr running in the logged-in Mac session. Move the device to another Wi-Fi network and keep it unlocked with the VPN connected. Cellular-only operation is unsupported.
  5. Download the matching Claude Code or Codex plugin ZIP from Releases. Extract it and follow its included README installation instructions.
  6. Run /Applications/Debagr.app/Contents/MacOS/Debagr --devices --json on the paired Mac. Select the intended Apple identifier, then run --status --device <UDID> --timeout 30 --json.
  7. Build a signed device .app on that Mac, or copy the complete signed artifact there. Run readiness again after building, then --deploy-app /absolute/path/App.app --device <UDID> --launch --json. Allow 180 seconds. Report success only when installed and launched are both true.

For a remote agent, use your existing SSH access as the same Mac user. The plugin does not set up SSH, signing or Apple trust. Alternative VPN providers and iPad still need full remote hardware acceptance.

On failure, run --diagnose --device <UDID> --timeout 30 --json and follow its recovery instruction. An installation timeout has an unknown outcome; inspect installed apps before retrying.
