This draft requires owner and legal review before sale.

## Licence

Subject to payment and these terms, the publisher grants one named user a
revocable, non-exclusive, non-transferable licence to install and use Debagr on
Macs and Target Devices owned or controlled by that user during the subscription
term. No ownership or source-code rights transfer.

## Requirements and deployment behavior

Debagr requires compatible Apple hardware and software plus the third-party
products disclosed before purchase. Device operations execute on the Build
Server that owns Apple's pairing relationship. Remote callers use the user's
existing remote-access service; Debagr does not transfer pairing state or make
the Target Device appear on the caller's machine. Operating system, Xcode,
device, signing, network, and third-party changes can interrupt deployment.

The user must not use Debagr to access hardware, networks, or data without
authorization; bypass Apple trust or pairing controls; resell access; reverse
engineer except where law forbids that restriction; or use the software where a
failure could cause injury, data loss, or safety-critical harm.

## Updates, support, and refunds

The active subscription includes compatible updates and the support policy
published at purchase. The publisher may narrow the compatibility matrix when
platform changes make a configuration unsafe or infeasible. State the final
trial, cancellation, and refund terms in the checkout and support policy.
