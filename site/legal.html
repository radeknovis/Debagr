Privacy, Security & Licensing

Local-first by design.

Debagr has no cloud backend, no accounts, no analytics, no telemetry, and no billing infrastructure.

Privacy Policy

  • Zero collection: Debagr never transmits telemetry, usage metrics, crash reports, device identifiers, or app metadata to any Debagr server.
  • Local restrictive storage: Configuration, deployment receipts, and bridge state are stored solely on your Builder Mac inside ~/Library/Application Support/Debagr with POSIX 0700 directory and 0600 file permissions.
  • Redacted diagnostics: Running debagr doctor or clicking Copy Redacted Diagnostics automatically redacts UDIDs, strips Bonjour wireless pairing instance names and TXT records, and masks VPN IP octets by default.

Security Boundaries

  • SSH remains the remote authentication boundary: Debagr does not open a network listener for deployment commands.
  • Private VPN address validation: Wireless endpoints are validated against private VPN ranges (RFC 1918, 100.64.0.0/10, IPv6 ULA fc00::/7). Public internet IPs, loopback, and link-local ranges are rejected.
  • Experimental two-Mac security: Experimental USB/IP pairing uses ephemeral Curve25519 ECDH + 6-digit SAS mutual role authentication + ChaCha20-Poly1305 encrypted control frames, never bundles third-party drivers, and requires explicit user confirmation before launching external tools.
